# RepoTracker Windows x64 便携预览版

0.5.0 提供标准 Setup 安装包，推荐使用它安装和升级：登记应用路径、开始菜单与卸载入口，新版本沿用同一程序目录，保留设置。详细步骤见随包 `INSTALL.md`（源码为[安装与升级](安装与升级.md)）。本文同时保留 ZIP 的便携使用方法。

解压完整 ZIP 到固定的本地文件夹，再运行 `RepoTracker.Desktop.exe`。不要在压缩文件预览窗口里直接运行，也不要只复制 exe。程序包含 .NET 与 WPF 运行时；仓库检查还需要已安装的 Git，且 `git --version` 能在终端运行。当前实测环境为 Windows 10 x64；其他 Windows / DPI 组合以项目验收记录为准。

Setup 与 ZIP 都尚未签名，没有后台联网下载更新服务。包版本、构建 SDK、运行时、源码提交及是否含未提交改动见 `package-manifest.json`；发布文件旁的 `.sha256` 是对应校验值。实际支持范围见 `COMPATIBILITY.md`。

当前版本为 `0.5.1`，支持手动添加子仓库、重复检查、图标状态与折叠汇总，并修复展开箭头外框、图标间距及对齐。随包运行时版本以 `package-manifest.json` 为准；运行时更新随应用新包发布，安装版运行新版 Setup 即可更新。

## 首次使用与语言

首次启动显示空列表，点击“添加仓库”选择本地 Git 工作树。可创建分组、调整设置；远程检查默认关闭，主动开启才会连接配置的 Git 远端。收起隐藏到托盘，展开也不占任务栏；退出使用菜单“退出”或 Alt+F4。

界面默认跟随 Windows 显示语言，支持简体中文和英文，其他语言回退英文。设置中可选“跟随系统”、简体中文或 English，保存后下次启动生效；仓库名和自定义分组名不会被翻译。系统日期 / 数字区域格式与界面语言分开。

默认数据目录为 `%LOCALAPPDATA%\RepoTracker`，存放配置、备份和日志。首次启动建立日志目录，第一次成功修改设置或清单后保存 `state.json`。程序目录不存用户配置。需要独立配置时，使用 `RepoTracker.Desktop.exe --profile "C:\绝对路径\个人配置"`；同一配置只运行一个实例。

## 子仓库

普通添加只跟踪指定仓库。父仓库行更多菜单提供“添加子仓库…”，输入或浏览选择独立 Git 工作树，新条目继承父分组。应用按实际工作树根跨分组检查重复；普通子目录、父仓库本身和父目录之外的仓库会被拒绝。取消不修改清单。

主列表在同一分组内按目录关系显示父子层级；点左侧箭头展开或折叠，状态跨重启保留。每行使用 `✓`、`●`、`↑`、`↓` 等图标表示状态；折叠后仍显示所有层级子仓库未提交、待推送和待拉取的仓库数，悬停查看详细说明。移组或移除只作用于当前仓库；重复添加隐藏的子仓库会展开并定位。

添加不会扫描目录、执行 fetch、pull 或子模块初始化；支持普通嵌套仓库、已初始化子模块和 linked worktree。远程检查默认关闭，领先 / 落后仅根据本地已知上游计算；开启远程检查后才更新远端信息。

`✓` 表示工作区干净，`—` 可表示当前分支未设置上游；二者可以同时出现。未设置上游不等于没有远程仓库，只是当前没有明确的推拉比较目标。子仓库汇总用 `—n` 单列这些情况，悬停查看具体原因，`?n` 仅表示尚未取得完整状态。应用不会自动修改分支 tracking。

## 托盘与登录启动

程序运行时保留右下角托盘图标，主面板不占任务栏或 Alt+Tab。单击托盘图标打开面板，右键提供打开、设置、退出；已有设置或文件选择窗口时，先完成该窗口再执行托盘设置或退出。退出会结束后台检查并移除当前托盘图标。

若图标在右下角的“显示隐藏的图标”小箭头内，将 RepoTracker 图标拖到外面，或在 Windows 的“设置 → 个性化 → 任务栏”中开启它的显示。Windows 10 对应“选择哪些图标显示在任务栏上”，Windows 11 对应“其他系统托盘图标”（名称可能随版本变化）。应用不能强制绕过 Windows 的图标收纳设置，换电脑或移动程序目录后可能需要重新选择。[微软任务栏说明](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows)。

登录自启默认关闭。进入应用“设置 → 检查与窗口”，向下滚动并勾选“登录 Windows 时启动”，修改自动保存。此开关登记在当前电脑、当前 Windows 用户下，复制程序或配置到另一台电脑不会复制自启登记。下一次登录时仅显示托盘；安装版升级保持同一路径和自启偏好。

## 升级与移动

安装版直接运行新版 Setup，不要手动移动程序文件夹。以下步骤仅用于仍选择 ZIP 的便携用户。

1. 通过应用菜单“退出”，确认进程结束；仅收起窗口不算退出。旧版本仍运行时，新 exe 只会唤醒旧进程，无法切换到新功能。备份数据目录中的 `state.json` 和 `state.json.bak`（如有）。
2. 将新版本解压到新的空文件夹，保留旧文件夹作为回退依据，避免覆盖混入旧版运行时文件。
3. 若需保持原有登录启动路径，将原程序文件夹改名保留，再将新文件夹改为原路径。使用同一默认数据目录或同一个 `--profile` 启动；仓库、分组和语言会读回。
4. 若改用另一程序路径，先在旧版本关闭“登录 Windows 时启动”，退出后在新路径重新打开该开关。保留旧项时新路径不会显示已启用；开启新路径会更新该 profile 的登记，旧路径不能误删已更新的命令。

未知更高版本的配置会以只读方式打开。回退旧程序前请保留升级后的配置，并使用对应版本的备份；不要以清空配置解决兼容问题。

## 卸载与数据保留

安装版从 Windows“设置 → 应用”卸载，自动移除程序登记和指向本安装位置的自启项，保留外部数据。以下步骤适用于 ZIP。

先在设置里关闭“登录 Windows 时启动”，再退出并删除程序文件夹。便携版不自动移除 Windows 自启登记；直接删目录可能留下失效登记。自启开关只处理当前 profile；使用多个 profile 时分别关闭。若已删除程序，可恢复到原路径后关闭开关。

卸载程序文件夹会保留 `%LOCALAPPDATA%\RepoTracker` 或指定的 profile；也不会删除跟踪的仓库。确认不再需要后，可以自行备份或删除自己的配置目录。程序与 profile 请放在不同目录，避免手动删除程序时连同数据一起删除。

## 常见问题

- 无法检查仓库：先在终端运行 `git --version`；安装 Git 后重新启动应用，让它读取新的 PATH。目录失效时修复目录访问，不必删除原配置。
- 开启远程后提示需要认证：先在应用外完成 Git 的登录 / 密钥和主机确认，再重试；应用不会弹凭据窗口。关闭远程不影响本地状态采集。
- 修改配置失败：检查当前 profile 是否可写、是否被外部程序改动；不要直接清空数据目录。未来 schema 会以只读方式保护原文件。
- 损坏配置：程序保留损坏副本并尝试有效备份；请先备份整个 profile，再根据日志处理，勿把备份覆盖到仍运行的实例。
- 登录自启失败：保持程序路径稳定；exe、profile 与参数组成的命令有长度限制，过长时选择较短的路径。迁移路径按上方步骤重新登记。
- 需要诊断：提供版本、Windows 版本、DPI、复现步骤及相关日志片段。日志位于 profile 的 `logs/`；分享前检查个人路径等信息，不发送凭据或未经检查的完整配置。

## English quick start

Use the Setup EXE for a registered per-user installation. New installers reuse the same location and preserve settings; uninstall through Windows Settings. There is no background update downloader. The app keeps a tray icon and does not show a main taskbar button. Click the tray icon to open the panel; right-click for settings or exit. Login startup is off by default.

Extract the entire ZIP into a stable local folder and run `RepoTracker.Desktop.exe`. The .NET/WPF runtime is bundled; install Git separately and make it available on PATH. The interface follows the Windows display language by default (Simplified Chinese or English, with English fallback). A saved language override takes effect after restarting.

Settings and repository lists are stored in `%LOCALAPPDATA%\RepoTracker`, or the absolute directory supplied with `--profile`. Setup upgrades preserve this external profile and the installed path. For ZIP upgrades, exit first, extract into an empty folder, and retain your profile and a backup. Removing application files preserves external profiles and tracked repositories. Distribution is currently unsigned; see `INSTALL.md`.

See `COMPATIBILITY.md` for tested environments and limitations. Runtime patches are delivered with a new full application package. Windows 10 Pro 22H2 was tested locally; this is not a vendor support claim.

运行时许可证见包内 `licenses/`，第三方组件与图形说明见 `THIRD-PARTY-NOTICES.md`。
