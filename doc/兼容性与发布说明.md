# 兼容性与发布说明

核查日期：2026-10-18。当前版本为 Windows x64 本地便携预览版 `0.4.0-preview.5`，添加时默认扫描子仓库并显示进度，保留展开层级与托盘入口；打包固定 .NET / WPF 10.0.13，未签名，沿用既有平台边界。以下区分实际运行验证、规则测试和供应商支持条件；不把模拟 DPI 当作物理高 DPI 验收。

Windows 10 Home / Pro 22H2 已于 2025-10-14 结束标准支持；本机 ESU 状态未核验。运行通过不构成对该系统的官方支持声明。部署到生产或公开分发时，应选择仍受支持的 Windows 版本，并在该版本完成实测。[Windows 生命周期](https://learn.microsoft.com/en-us/lifecycle/products/windows-10-home-and-pro)、[.NET 10 支持的系统](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)。

微软 2026-10-13 的 .NET 更新包含 10.0.13；旧预览版 0.4.0-preview.1 包含 10.0.12，仅保留为历史验收产物。自包含应用需要重新发布以更新随包运行时，不会自动使用电脑上较新的共享运行时。今后打包前应重新核对补丁；本说明不声称 10.0.13 永远为最新版。[支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)。

## 功能与交付边界

- 默认按 Windows 显示语言选择简体中文或英文，不支持的语言回退英文。手动语言选择在重启后生效；系统显示语言的真实切换没有修改用户电脑来验证。
- `preview.5` 运行 `dotnet test RepoTracker.slnx --configuration Release --no-build --no-restore --filter 'FullyQualifiedName!~GitProcessTests'`，202 项通过（Core 119、Integration 74、Desktop 9），0 失败、0 跳过；含默认添加扫描、可选关闭、时间限制、托盘、多层展开、折叠后检查、移组 / 移除、重启恢复。另 2 个原有进程超时 / 取消用例因 PowerShell 夹具启动受限未通过，本轮筛选排除，不能称为全量通过。Release 构建 0 警告、0 错误。打包验收另由进程外 UI Automation 驱动实际解压 exe。Git 的真实成功远端 fetch、命名分支 ahead/behind 等仍按历史记录区分协议测试与真实集成测试。
- 固定 20 仓库性能基线是在 Runtime 10.0.12 上测得；不能把它写成 10.0.13 已重复测量或大型仓库、全天运行的保证。
- 同一包移动到新目录后保留配置已测；两个历史发行版本之间的端到端升级未测。便携卸载前需要在应用关闭自启，删除目录不自动清理 Windows Run 项。
- 本地预览包无 MSI、签名、自动更新、系统信任信誉验收。仓库尚未选择本项目的对外开源许可证；第三方许可不自动覆盖本项目。对外正式发布前仍需明确发行授权及品牌素材使用条件。

这些未覆盖项不妨碍在已验证本机使用预览包，也不作为已支持的产品承诺。使用、升级和移除步骤见包内 `README.md`；第三方原文许可见 `licenses/` 和 `THIRD-PARTY-NOTICES.md`。
