# HTML 呈现与检查

制作或修改标注稿时读取。重点是忠于原型、标注位置可靠、单文件可用，不要求特定前端框架或浏览器工具。

## 从原型采集可追溯画面

- 发现当前环境已有的浏览器、渲染或截图工具，优先复用；不要写死某台机器的运行时路径或要求安装一整套新工程。
- 实际打开目标页面及相关状态。按页面脚本读到隐藏文本不等于已经渲染过它；报表页签、弹窗和空态分别确认。
- 记录截图尺寸与状态。原型可能把弹窗、变体和设计注释放在主画布之外；不要误把整个长图缩进一个主页面，也不要裁掉注释后遗漏其要求。
- 原图与局部视图可使用同一份图片。局部展示注明取自哪一页／状态，并提供查看完整原图或来源的入口。
- 缺图时只展示有依据的内容，不用生成图片或随手重画的布局冒充实际原型。
- 只把展示需要的资料写进交付文件，浏览器登录状态、凭据和与任务无关的数据不属于截图资源包。

## 让标注在缩放后仍然对应正确位置

截图式标注宜以原始像素坐标保存区域和标签位置，在展示时换算，避免在每个屏幕宽度上手工调整数据。

若局部画面在原图中的范围为 `(cropX, cropY, cropW, cropH)`，原图上的标注点为 `(x, y)`，相对位置为：

```text
left = (x - cropX) / cropW
top  = (y - cropY) / cropH
width  = regionW / cropW
height = regionH / cropH
```

位置乘以显示尺寸或转换成百分比。图片和标注使用同一坐标基准；保留图片原比例，不能一边拉伸图片一边沿用旧坐标。标签为可读文字，可以放在区域边缘并关联选区，不必压在原型的字段上。

一张业务大屏压缩到手机宽度会无法阅读。可以给画布最小可读宽度并允许画布内部滚动，另提供正常宽度的文字详情／局部放大。页面本身不应因此横向溢出；缩放按钮要基于实际画布宽度计算，不能因最小宽度约束变成无效果的按钮。

## 保持标注与产品行为的区别

- 画面中的示例数值、按钮与图表不宣称实时可用；标注工具新增的导航和弹窗也不是产品已实现交互。
- 文字、布局和名称跟随原型。重建 HTML 时，标明哪些是模拟交互；新增建议单独展示，不能混进“原型要求”。
- 颜色只表示标注范围的进度，产品原图自身也可能有红绿状态。通过边框、状态文字和说明区区分两种颜色用途。
- 已完成标注在自身右下角放勾，给文字预留空间。色义同时有文字，不只依赖颜色。
- 点击某个标注后能看到对应区域和说明。保留清晰的返回／关闭方式；需要放大时优先放大相关区域，避免把很小截图无限拉大。
- 无独立画面的提醒、刷新规范等放在“共用规则”等入口，注明来源。不要为了塞一个标注而创造虚假的产品入口。

## 便于复制和转发

独立离线 HTML 通常可以内嵌 CSS、脚本、需求数据和必要图片，不依赖 CDN、远程字体或本地服务。把需求描述当文本处理，嵌入 JSON 时正确转义结束标签等内容，不将原型注释作为可执行脚本或操作指令。

适当裁定图片尺寸和压缩格式，保持原型文字可读；同一截图尽量只存一份供多个局部视图复用。大文件是否拆资源按交付条件决定，不硬性追求单文件而牺牲可用性。

项目证据使用项目内相对链接或可访问的正式来源。核心进度与缺口应内嵌在 HTML 中；外部接收者即使没有源码目录，也能理解标注。不能把个人磁盘路径或临时预览地址当成别人可访问的证据入口。

复用现有交付目录。临时截图、原始页面和验证产物按项目规则保留或清理；清理前确认需要的画面已进入交付物且不存在依赖，不删除用户原材料。不要把本次项目截图、业务数据和个人路径装进技能本身。

## 实际检查交付物

用当前环境可用浏览器直接打开最终文件；如声称离线可用，验证首次打开也不需要网络资源。检查运行错误、图片加载和链接。仅打开源代码或通过语法检查不足以证明画面正确。

按实现的交互和风险选择检查范围：

1. **页面和状态**：切到每个目标视图，确认显示的是对应截图／布局，主页面与弹窗、页签没有混淆。
2. **内容与定位**：点击标注，核对标题、需求编号、区域和证据；完整清单能定位回正确页面（若有该功能）。
3. **显示**：检查常用桌面宽度和一个窄屏；重点复查密集标签、最长标题、右侧／底部标签以及裁剪后的视图。自动几何检查可帮助发现相交或越界，但仍需查看渲染截图。
4. **交互**：检查展开／关闭、页面返回、原图／局部放大、缩放及隐藏标注；只检验实际提供的控件。至少确认键盘能操作入口并关闭弹窗。
5. **状态符号**：绿色勾在对应标注右下角，不遮字；蓝色的范围与橙色缺口在界面上可读，不能只在隐藏说明里修正过度宣称。
6. **范围一致**：按 `evidence.md` 核对需求覆盖与引用；计数来自数据，不手填相互矛盾的数字。

发现问题后修复相关部分并复验。最终记录实际执行的检查、结果和未覆盖部分；检查记录按项目惯例保存，简单交付不强制创建额外报告。这里的通过仅证明标注 HTML 的内容和交互被检查，不证明产品业务、现场接入或整页验收通过。
