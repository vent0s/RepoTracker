## 第一阶段：明确技术与状态语义（已完成）

以仓库 [README](../../../README.md) 的现有未提交内容作为本次需求基线：Windows 常驻、手动添加、只查看仓库状态、自建 Git 来源、分层采集。首次设计之后，用户明确主入口为任务栏应用按钮，已同步 README 对应段落。启动本工作区时仓库没有产品源码或已有 devSchedule 工作区。

首轮结论见 [概述](概述.md)：推荐 C# / WPF / .NET 10 / Git CLI，保留 Tauri 2 作为后续跨平台需求出现时的候选；现已随用户确认进入开发基线。特别明确：fetch 会写入 Git 元数据；无上游和未知的远程新鲜度不能显示成“已同步”。

验证：已查询官方文档；本机有 .NET SDK 10.0.201、WindowsDesktop Runtime 10.0.5 和 Git 2.51.0.windows.1。未安装依赖、未运行 fetch、未修改 Git 配置。验收依据为 [H-01](harness.md#h-01需求与选型对应)。

## 第二阶段：完成可评审的 Penpot 原型（已完成）

目标文件：RepoTracker（内部访问地址已省略）。原页面为空；通过该实例的 MCP 创建原生画板、文字、矢量图标与交互。

范围：主面板、空状态、离线数据、保持展开、浅色对照、添加校验、移除确认与撤销、检查设置、已知来源及新规则。细节见 [原型规格](原型规格.md)。基础设计源保存在 [penpot-prototype.js](../design/penpot-prototype.js)，不含认证信息，不是桌面应用代码。

完成条件：H-02 的文件与图层检查、H-03 的交互目标检查、H-04 的导出视觉检查、H-05 的文档检查通过。真实 OS 行为留待桌面实现验收，不以静态原型替代。

首次完成结果：26 个画板、1,963 个后代图层（其中 529 个文本）、137 个交互、6 个演示入口、6 个状态组件及 30 个颜色资产。10/10 关键关系通过。首版历史证据见 [结构 JSON](../design/evidence/penpot-audit-v1.json)、[主面板](../design/evidence/main.png)、[设置](../design/evidence/settings.png)、[设计说明](../design/evidence/guide.png)、来源新增（原截图含本机环境信息，公开版本已移除）、[首次添加](../design/evidence/firstMain.png)和[浅色对照](../design/evidence/light.png)；这些 PNG 保留首版外观，当前入口以以下修订为准。

### 2026-10-16：任务栏入口修订（已完成）

按用户“任务栏里可以直接点击展开”的反馈，新增收起与展开两个桌面场景，任务栏图标与标题栏收起按钮形成往返；增加应用内菜单，将图钉定义为“保持展开”。README、技术选型和原型规格已同步，WPF 推荐不变，实施重点转为标准任务栏窗口生命周期。修订源见 [penpot-taskbar.js](../design/penpot-taskbar.js)。

该轮复验结果：28 个画板、2,317 个后代图层（589 个文本）、170 个交互、6 个演示入口；16/16 关键关系通过，添加 / 移除 / 首次添加后仍为 7 / 5 / 1 个仓库。无图层越界、文本溢出、画板重叠或失效目标。历史证据为[结构 JSON](../design/evidence/penpot-audit-taskbar.json)、[任务栏收起](../design/evidence/taskbar-closed.png)、[任务栏展开](../design/evidence/taskbar-open.png)。未修改 Windows 任务栏设置，未验证真实系统激活、DPI 或精确定位。

### 2026-10-16：手动分组增量（已完成）

用户确认“我觉得没问题了”后追加手动分组。沿用已认可的任务栏入口与视觉方向，增加一层、单归属的分组，新建、改名、移动和删除只修改应用配置；删除分组把仓库移回未分组，折叠不暂停状态采集。README 与[选型依据](概述.md#手动分组模型)已同步数据模型、旧配置回退和原子保存要求。

设计源见 [penpot-groups.js](../design/penpot-groups.js)，验收见 [H-06](harness.md#h-06手动分组增量)。新建使用工具组，移动以 repotracker 为例，重命名使用工作组，删除使用含两个仓库的个人组。原型为预设点击路径；自由输入、任意状态组合及桌面持久化不在本轮冒称实现。

结果：新增 12 个分组画板，合计 40 个画板、4,074 个后代图层（1,010 个文本）、293 个交互、7 个演示入口。29/29 关键关系通过；移动后仓库唯一且总数不变，改名保持归属，删除个人组后 6 个仓库全部保留。图层越界、文本溢出、画板重叠和失效目标均为 0。当前证据为[结构 JSON](../design/evidence/penpot-audit.json)和[分组主面板](../design/evidence/groups-main.png)。后续任务栏和弹窗截图导出超时，未冒称逐张完成视觉检查；限制见 harness。
