# M5 多语言增量验收

> 公开版本说明：本机环境信息已脱敏，示例路径与标识不用于定位原始私有产物。

2026-10-17 用户追加多语言支持，默认随系统语言显示。本轮实现简体中文和 English，默认保存 system；语言选择、旧配置兼容、真实窗口和跨进程恢复已验证。唯一进度入口为[开发里程碑](里程碑-桌面应用开发.md)。

## 实现与验证范围

- 249 条英文基准资源及简体中文翻译，覆盖主面板、菜单、设置、分组与仓库弹窗、状态、校验、错误及可访问名称。占位符一致且可格式化。
- 简体中文系统变体映射到 zh-Hans，英文及未支持的系统语言使用 English；手动选择优先。语言名显示为自称，用户文本不翻译。
- schema 4 的可选 language 字段默认 system；缺字段及未知代码不会丢失仓库、分组或其他偏好。保存失败保留旧状态；语言保存后明确告知下次启动生效。
- 启动先读取偏好，再确定文案语言和创建窗口；后台检查与主窗口使用同一语言。数字 / 日期区域格式与 Git 的 C 协议环境不被改写。

真实窗口四组场景为：zh-CN + system、en-US + system、de-DE + system、zh-CN + en。每组验证启动文案和状态、手动选择另一种语言、失败保存与成功保存，并用同一 profile 重启检查。真实窗口 150% 应用缩放及英文布局已截图复核，中文自定义名称仍保持原样。

## 保留的边界

本轮未修改用户 Windows 显示语言、注销系统或更改物理 DPI。不同系统语言的输入由测试宿主设置启动线程 CurrentUICulture；这验证应用选择与显示，不等同于逐种 Windows 语言包实机测试。当前只提供简体中文和 English，繁体中文等语言使用英文回退；Windows 原生对话框的系统按钮由操作系统决定语言。

原有真实登录启动、真实服务成功 fetch、Windows 11、物理高 DPI / 混合 DPI、任务栏固定 / 自动隐藏等边界仍按[M5 原验收记录](M5验收记录.md)保留。M6 性能、安装交付尚未实施。
