```text

```

源码基点为 `db276574f29121051066f9199a194087fb6fadf1`，包包含本轮尚未提交的实现，`SourceDirty=true`；不是该提交本身的发行物，也未建立 tag / 上传远端。当前主分支与远端 main 的提交值只读核对一致。所有包、中间产物和原始证据均已被 Git 忽略，不将大型二进制 / JSON 加入提交。

本机 Windows 10 Pro 22H2 build 19045、x64、Git 2.56.0.windows.2。锁定 SDK 10.0.201 本机未安装；本轮通过显式 `-SdkVersion 10.0.401` 完成兼容构建，清单同时记录锁定与实际版本。未改根 `global.json`。不带兼容参数的入口在本机如预期拒绝构建，没有隐式回退或输出 ZIP。

## 可复现入口

```powershell
pwsh -File publish-win-x64.ps1 -SdkVersion 10.0.401
pwsh -File tests/run-package.ps1 -PackageZip "publish/20261017-164607-ba34b8/RepoTracker-0.4.0-preview.1-win-x64.zip"
```

正常构建机器安装锁定 SDK 后省略 `-SdkVersion`。脚本在新的忽略目录内创建局部 SDK 锁定和隔离中间产物，使用 Release、win-x64、self-contained、锁定依赖恢复。三份生产 `packages.lock.json` 已加入 win-x64，普通 solution 恢复亦通过 `--locked-mode`。包含英文中性资源、中文卫星资源、便携说明、已有图标说明及两个运行时包的许可 / 第三方声明。清单保护各文件哈希，ZIP 另带整体哈希。

时间、目录名和 ZIP 元数据会变化；“可复现入口”不表示不同构建的 ZIP 字节完全相同。发布版本及包用途尚为本地预览；最终产品许可证和来源审阅由 M6-03 统一处理。

## 升级 / 卸载边界

配置默认位于 `%LOCALAPPDATA%/RepoTracker`，或用户显式指定的外部 profile。便携版在退出后解压新版本、保留原配置即可；保持原程序路径可沿用自启命令，迁移路径则先关闭旧路径的自启，再在新路径启用。卸载前关闭每个 profile 的登录启动、正常退出，再删除程序目录；不会自动注销自启项。直接删目录可能留下失效登记，不能称为自动卸载清理已实现。完整中英说明见[便携版使用说明](../../../doc/便携版使用说明.md)。

未覆盖：干净且未安装 .NET 的系统、真实 Windows 登录 / 注销、历史发行版本互相升级、Windows 11、其他架构、物理高 / 混合 DPI、签名与安全软件信誉、MSI 安装卸载。包内模块路径已验证不依赖本机共享 .NET，但不能代替干净系统的原生依赖验收。Windows 10 的实际启动也不等于该系统和 .NET 的供应商支持条件已完成核查；M6-03 仍需整理正式矩阵和支持边界。
