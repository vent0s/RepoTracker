# 桌面应用开发 — 验收说明

本文件规定产品实现的验证方式。**H-01 至 H-09 的原定本机范围已有历史验收；10-18 增加 H-10 托盘与 H-11 子仓库场景，当前筛选回归 202 项通过。另两项 H-05 相关原有进程夹具失败仍未解决，不能宣称全套通过。** H-04 的真实分支 / 上游组合和 H-05 的物理睡眠组合等边界见下文，协议与替身通过不代表所有实机组合通过。任务状态只维护在[里程碑](里程碑-桌面应用开发.md)。

## 共用测试准备与证据

由 Codex 直接运行能力范围内的验证，复用工程长期测试入口，不生成一次性 verify / validate 批处理，也不要求用户代跑命令。需要最终主观判断或缺少的实机环境时，仅把该部分列为未验证。

测试目录使用当前项目下的 `tests/artifacts/<run-id>/`，已注入专用配置目录、Git 进程适配与可控时钟。10-16 历史记录使用 E 盘，10-17 当前工作区位于 C 盘；不复制工程来运行测试。日志、TRX、截图及性能记录按场景归档，记录命令、退出码、环境与未覆盖项；大体积输出不作为源码提交，保留可复现输入与结果摘要。

只操作明确隔离的测试数据与进程，不复用真实业务栈、用户配置或真实仓库作为可写夹具。不访问生产凭据或真实远端来模拟错误。清理前验证解析后的绝对路径仍在本轮测试根下；不创建工程副本。

遵守用户禁止自行创建分支的约束。先用文本样例、进程替身和不创建命名分支的隔离 Git 场景验证；需要命名分支或 upstream 的场景使用已有且获准的专用夹具。若必须新建分支，执行当次先取得具体仓库和分支名的授权，不通过 push 或直接写 refs 绕过限制。条件未齐时保留该集成项未验证，其余检查继续；产品自身始终不创建分支或设置 upstream。

M1 已建立以下可复用入口。桌面项需要已登录的交互式 Windows 桌面，不能用无头或隔离沙箱的焦点结果替代：

```powershell
dotnet restore RepoTracker.slnx --locked-mode
dotnet build RepoTracker.slnx --configuration Release --no-restore
dotnet test RepoTracker.slnx --configuration Release --no-build --logger trx --results-directory tests/artifacts/results
```

阶段测试需覆盖变化的行为，失败先修复复验；检查通过后不为增加次数重复跑全套。SDK、集中依赖版本和 package lock 已建立；按项目单独测试和便携发布的命令及环境说明见[开发与运行](../../../doc/开发与运行.md)。

## H-08：性能与发行

使用固定 20 个测试仓库，记录机器、文件数量及未跟踪内容规模。预热后在面板收起且远程关闭状态采样 5 分钟，再测打开列表、密集变更和开启远程的场景；统计应用与 Git 子进程总 CPU、工作集、进程数、检查耗时及 UI 响应。

预期：并发边界成立、没有孤儿进程或随轮数持续增长的资源，打开面板不被后台任务卡住。先将首轮测量作为可复现基线，再明确数值门槛并复验；未经测量不宣称“10MB”或“内存最低”。异常先定位队列积压、监听器和快照生命周期。

性能入口为 `pwsh -File tests/run-performance.ps1`，先完成 Release 构建；`-Smoke` 仅验证编排，不算性能验收。真实 App 使用独立 profile 和 20 个 detached HEAD 仓库，每仓库 201 个已跟踪文件及 50 个未跟踪文件。预热 30 秒，然后依次收起 300 秒、展开 60 秒、持续写入 60 秒、远程失败 90 秒、关闭远程并收起恢复 120 秒。远程阶段使用 1 分钟间隔加速覆盖，只连接测试自有回环端点。

CPU 和累计子进程数由 Windows Job Object 计量，包含已经退出的短命 Git 后代进程；独立写入器在 Job 外。每秒采样应用工作集、私有内存、句柄、线程与托管分配，记录调度检查耗时及 Input 优先级 Dispatcher 延迟。子进程工作集和同时存活进程数的采样峰值是下界；窗口恢复记录到下一次 Rendering 事件的时间，不能当作显示器呈现时延。测量宿主和回环服务自身开销计入应用成本，不强制 GC。

建立 Release 发布命令，检查依赖 / 运行时、首次启动、配置创建、重启、升级、卸载与自启清理；核对图标来源、依赖许可和可用系统矩阵。预期交付包可复现且行为与设计一致，记录版本、包哈希与未覆盖组合。签名、安装方式、额外架构仅按实际完成情况声明。
